Chosen tier direction: stricter Starter. Implemented active SKU / per-import
row defaults: Starter 500 / 1,000; Growth 25,000 / 100,000; Pro 250,000 /
1,000,000; Custom 2,000,000 / 5,000,000. Account-wide SKU/product counters,
contract overrides, paid product capacity and downgrade protections are wired
through PostgreSQL and billing/pricing. Other existing limits remain enforced.

Implemented and under verification:
- Monotonic ERP physical-count snapshots; stale updates and conflicting versions
  cannot overwrite stock. Ordering checkpoint and stock effect commit together.
- Serial/batch membership and lot balances survive receipt, issue, transfer,
  dispatch, arrival and returns. Expired issues require explicit disposal.
- No silent CSV row/column truncation, incomplete quoted fields or XLSX columns.
- Indexed delimited reader retains compact offsets; exact duplicate/conflict
  checks spill to temporary indexed storage for large sources.
- Validation scopes existing stock to each 500-row page. Approval identities are
  indexed during background analysis so approval need not load the full source.
- Execution and final reconciliation read saved pages. Catalogue preparation
  also pages variants within a single large family. Durable retry remains intact.
- Sparse planning positions replace SKU-by-location Cartesian expansion.
  Forecast/purchasing pages expose continuation; worker recommendations follow
  the existing durable SKU continuation. Purchasing no longer sums both a
  workspace total and its component location totals.
